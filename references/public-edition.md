# 正式版与 Alpha 版

本项目只有一份源码，构建时产生两个版本：

| 版本 | 入口 | PLC 轴动作 | 用途 |
|---|---|---|---|
| 正式版 | 本目录 | 硬性禁止 | 正式版，给一般现场和公开仓库 |
| Alpha 版 | 源码根目录 | 支持三类轴动作 | 内部验证版，先核对轴配置再生成 |

## 正式版硬性禁止 PLC 轴动作

> **安全警告：PLC 轴运动一旦轴号、`Pr21~` 配置、轴群状态、数据寄存器或宏
> 合同有误，可能导致撞机、设备损坏或人身伤害。正式版不提供上述任何轴安全
> 校验，因此不存在“安全使用”的路径。**

- 严禁在正式版中生成、拼接、手改、`patch` 写入或以任何方式注入 PLC 轴运动
  记录；Alpha 版支持的 `AX MOVE` / `AX RUN` / `AX STOP` 同样在正式版禁止。
- 严禁绕过 `AXIS_GENERATION` / `axis_not_supported` 门禁，或把 Alpha 版生成
  的轴记录复制、粘贴、合并到正式版产物中。
- 严禁用正式版修改含轴记录的程序来“顺带”保留轴逻辑；正式版不承担这类文件
  的写入安全。
- 收到轴相关需求时立即停止写入，并告知用户：必须改用 Alpha 版，且先完成
  `Pr21~`、轴群状态、`AX MOVE` 的四个连续寄存器、`AX RUN` 的 `O####`
  宏合同和现场安全评审。
- 本文件是正式版的强制策略。正式版 README 不记录轴动作写法，避免被误用。

除轴动作外，两个版本的 R 分区、`@` 公用变量映射、资源规划、注释分级和原生
校验能力一致。

## 版本标识

- 正式版：版本号见 `VERSION` 文件，`syntec_lad/edition.py` 中
  `EDITION = "public"`、`AXIS_GENERATION = False`。
- Alpha 版：根目录 `syntec_lad/edition.py` 中 `EDITION = "alpha"`、
  `AXIS_GENERATION = True`。
