# M 码标准写法：S29 + R1 + C38

> 一句话结论：M 码不是“比较 R1 后输出一个线圈”。标准链路是
> `S29` 读入、`R1` 取号、每个 M 一个请求位、完成条件满足后由 `C38`
> 放行 CNC。等待型 M 码执行期间必须把 `C38` 拉低。

本文的现场证据来自：

- `M码范例.lad`：M03/M04/M05/M08/M09/M19/M50/M51 的标准解码、等待与
  `C38` 写法；
- `0717-1M码切削水开关.lad`：M08/M09 非等待型写法；
- `0717-3M码M50 M51主轴夹紧.lad`：M50/M51 的输出与到位互锁片段；
- 培训教材《PLC-M码》和《TechManual-阶梯图编写开发》的 M/S/T 码章节。

证据等级要分开看：

| 等级 | 内容 | 用法 |
|---|---|---|
| 官方规则 | `S29/R1/C38` 时序；等待型 M 码执行期间 `C38` OFF；`A50` 就绪 / `A51` 执行的两状态 MSD 范例 | 所有机台都适用 |
| 官方示例 | 非等待型用 `A70` 直通；M3/M4 等到转速到达 `I0` 并稳定 0.5 s 后完成 | 学结构，地址按本机点表替换 |
| 现场骨架 | `A050/A051/A070` 等某台机已验证的 C38 支路 | 只在原机保留或整段复制；不是通用标准 |
| 单机结构 | 某客户把切断位改成 `A052/A101/A188` 之类 | 只能当案例，不能写成“所有新代 PLC 都必须这样” |

## 1. 信号与寄存器

| 信号/地址 | 方向 | 含义 |
|---|---|---|
| `S029` | CNC → PLC | 执行到 M 码时 ON，直到 `C38` ON 后的下一个周期才 OFF |
| `R1` | CNC → PLC | 当前 M 码数值 |
| `S054` | CNC → PLC | 执行到 S 码时 ON |
| `R2` | CNC → PLC | 当前 S 码数值 |
| `S069` | CNC → PLC | 执行到 T 码时 ON |
| `R3` | CNC → PLC | 当前 T 码数值 |
| `S030` | CNC → PLC | 分布结束（轴运动结束）；该 M 码在加工档中需要等 G 码完成时串入 |
| `C038` | PLC → CNC | M/S/T 完成；**常态 ON**，等待型 M 码执行期间 OFF |
| `C036` | CNC → PLC | 急停 |
| `C037` | CNC → PLC | 复位命令 |
| `S032` | CNC → PLC | 复位状态 |

同一单节里同时有 M/S/T 码时，`S029`、`S054`、`S069` 会同时发出，
`R1`/`R2`/`R3` 分别保存 M/S/T 数值。

时序：

1. CNC 执行到 M 码，`S029` ON，M 号写入 `R1`；
2. PLC 解码并执行动作；
3. 等待型 M 码执行期间 `C038` 必须 OFF；
4. 完成条件满足后 `C038` ON；
5. 下一个周期 `S029` OFF，CNC 继续下一单节。

如果 `C038` 一直不 ON，控制器会停在当前单节，画面看起来一直在“加工中”。

## 2. 两类 M 码

| 类型 | 例子 | 是否处理 C38 |
|---|---|---|
| 非等待型 | M07 吹气、M08 切削液、M09 关闭、工作灯、排屑机 | 不处理，`C38` 保持 ON |
| 等待型 | M03/M04/M05 主轴、M19 定向、M50/M51 松夹刀、M52/M53 刀库 | 执行期间 OFF，完成确认后 ON |

“非等待”不是“不用写互锁”，而是**不需要让 CNC 等动作完成**。

## 3. 最小解码骨架

每个 M 码必须只在 `S029` 有效时解码，不能只比较 `R1`：

```text
LD S029
CMPE #00050 R0001 -> OUT A150
CMPE #00051 R0001 -> OUT A151
CMPE #00008 R0001 -> OUT A108
CMPE #00009 R0001 -> OUT A109
```

`M码范例.lad` 用一个 rung 解出全部 M 码；工程上更推荐**一个 M 一个
rung**，现场增删 M 码时只改一行，不会动到整段。

只要该 M 码在加工档的任何位置需要等待 G 码完成，解码条件就要串 `S030`；
不能因为某次单独下 M 码时没有 G 码就省略。M05、M19 是最常见的例子：

```text
LD S029
LD S030
CMPE #00005 R0001 -> OUT A105
```

## 4. 等待型 M 码的 C38 骨架

### 4.1 官方 MSD 最小模型

官方《阶梯图编写开发》的 MSD 范例只要求两个状态：

```text
A50 = MST 就绪；就绪时 C38 导通
A51 = MST 执行中；执行时 C38 关闭，通知 CNC 等待
A70 = M 码不等待完成（非等待型直通）
```

等待型动作的完成条件成立后，必须回到就绪状态，让 `C38` 恢复 ON。
非等待型（切削液、工作灯、排屑机）执行期间不需要关闭 `C38`。官方范例
用 `A108/A109` 解码 M08/M09，再触发 `A70`；用 `A103/A104` 解码 M03/M04，
等 `I0`（转速到达）稳定 0.5 s 后才完成。这里的 `I0`、`A108`、`A70`
都是示例地址，不是通用分配。

实现时只要求“状态语义”一致：就绪时 `C38` ON，执行中 `C38` OFF，
真实完成条件成立后回就绪。不要为了凑某个模板去改原机已经验证的
进入/切断/完成三段。

### 4.2 现场等待位集合骨架

`M码范例.lad` 用另一套等价写法，可以复用逻辑，不能照抄地址：

```text
# ① 当前没有等待型 M 码在执行
LDI A150
LDI A151
LDI A119
OUT A309

# ② A310 是 A309 的上一扫描状态
LD A309
OUT A310

# ③ M 码存在，且上一扫描没有等待型 M 码
LD S029
LD A310
OUT A308

# ④ C38 常态 ON；M 码存在时，只有 A308 才放行
LDI S029
OUT C038
LD A308
OUT C038
```

等价逻辑：

```text
A309 = !A150 & !A151 & !A119
A310 = A309 的上一扫描值
A308 = S029 & A310
C038 = !S029 | A308
```

这样写同时满足两类 M 码：

- 非等待型 M 码不会置位任何等待位，`A309` 一直为真，`C038` 保持 ON；
- 等待型 M 码一置位，`A309`/`A310`/`A308` 依次变假，`C038` 被拉低；
- 完成条件满足、等待位复位后，`A309` 恢复，下一扫描 `C038` 恢复 ON。

多 M 码项目也可以使用四旗标版本（执行中 `A270`、完成 `A271`、
等待执行 `A272`、等待结束 `A273`），逻辑相同，只是可读性更好。
见 `references/panming/function-library.md` 的 §5。

四旗标版本同样只是现场实现，不是官方固定地址。

## 5. 两个真实样本

### 5.1 M08 / M09：非等待型

`0717-1M码切削水开关.lad`：

```text
LD S029
CMPE #00008 R0001 -> OUT A108
CMPE #00009 R0001 -> OUT A109

A108 / !C037 / !C036 / !S032 / !A109 -> OUT O001
O001 自保持
```

- M08 置位 A108，O001 自保持开冷却；
- M09 的 A109 断开自保持；
- 急停 C036、复位 C037/S032 也断开；
- **不碰 C38**，因为冷却水不需要等动作完成。

### 5.2 M50 / M51：等待型

`0717-3M码M50 M51主轴夹紧.lad` 的片段：

```text
LD S029
CMPE #00050 R0001 -> OUT A150
CMPE #00051 R0001 -> OUT A151

A150 / !C036 -> OUT A250
A250 自保持，A151 复位

A250      -> OUT O020
!A250     -> OUT O021
```

这个样本只演示了**解码、命令保持和输出互锁**，还不是完整的产线写法。
按培训教材和原厂规格，M50/M51 还必须补：

- 夹刀/松刀到位信号：`I23`/`I24`（以本机 IO 点表为准）；
- 到位信号稳定确认：松刀 0.1 秒、夹刀 0.5 秒；
- 3 秒内未到位：报警并暂停加工，复位可解除；
- 等待期间 `C38` OFF，确认完成后 `C38` ON；
- 主轴正/反转时禁止松夹刀，主轴转速低于 10 RPM 才允许；
- 急停、复位必须清命令位和输出，不能松急停后自己继续动作。

样本里的 `O020`/`O021` 哪个是夹紧、哪个是松开，**必须按本机 IO 点表确认**，
不能按 M 号猜。不同机型的 M50/M51 定义可能相反。

### 5.3 不要按模板重写原机的 C38 支路

现场样本 `0717-1M码切削水开关.lad` 的骨架是：

```text
A050 就绪              -> OUT C038
A051 执行              -> 拉低 C038
S029 + R1 解码 M08/M09 -> A108/A109
非等待动作             -> A070 直通
```

`0717-3M码M50 M51主轴夹紧.lad` 也是 `A050/A051/A070` 这一组，不是
`A050/A051/A052/A188/A101`。某些改造记录里的
`A050/A051/A052/A101/A188` 是**该台机原梯形图的历史结构**，不是新代
官方对所有 PLC 的强制模板。

修改已有程序时：

1. 先 `inspect` 并定位原机 `C38` 支路，确认就绪位、执行位、完成位；
2. C38 支路逐字节保留，不因为“看起来可以简化”而重写；
3. 新 M/T 码只增加解码、动作输出和完成条件，或整段复制同一台机已经
   验证过的等待骨架；
4. 找不到原机 C38 支路、或无法判断某个 A 位是否通用时，停止生成，
   输出“待确认”，不要用别的机台地址补齐。

## 6. 常见 M 码与完成条件

以下是标准铣床教材的常见定义，实际机台仍以本机 M 码表和 IO 点表为准：

| M 码 | 功能 | 典型完成条件 |
|---|---|---|
| M03 | 主轴正转 | 主轴转速达到目标 80% |
| M04 | 主轴反转 | 主轴转速达到目标 80% |
| M05 | 主轴停止 | 转速低于 10 RPM 并确认停转；通常按等待型处理 |
| M07 | 加工吹气开 | 非等待 |
| M08 | 切削液开 | 非等待 |
| M09 | 吹气/切削液关 | 非等待 |
| M19 | 主轴定位 | `S61` 定位完成，3 秒超时 |
| M30 | 程序结束 | 关吹气/切削液、停主轴 |
| M37/M38 | 排屑机正/反转 | 按现场定义，通常非等待 |
| M50/M51 | 主轴松/夹刀 | 到位信号稳定，3 秒超时 |
| M52/M53 | 刀库推出/退回 | 到位信号稳定，10 秒超时 |

## 7. 检查表

写任何 M 码前先确认：

| 项目 | 必须确认 |
|---|---|
| 读入 | 是否串了 `S029`；该 M 码在加工档中需要等 G 码时是否串 `S030` |
| 号值 | `R1` 是否为本机 M 号，不能用别的寄存器代替 |
| 请求位 | 每个 M 一个独立 A 位，是否会被下一个 M 正确复位 |
| 输出 | 一个输出是否只有一个线圈；手动/自动是否共用同一个请求位 |
| 等待型 | 执行期间 `C38` 是否 OFF，完成后是否恢复 ON |
| 原机结构 | 原机 `C38` 支路是否保持原样；没有把案例地址当通用模板 |
| 完成 | 是否用实际到位信号，而不是“命令已发出”或固定延时 |
| 超时 | 是否有超时报警和复位路径 |
| 安全 | 急停 `C036`、复位 `C037`/`S032` 是否清请求位和输出 |

`plan-lint` 的 `mcode_wait_without_c38` 只能发现“整个计划完全没有 C38
写入”这一类明显缺件；它不能证明 C38 的布尔时序正确，也不能代替上机前
对等待位、完成条件和超时的逐条审查。

`mcode_decode_without_s029` 会检查比较 `R1` 的网络是否同时包含 `S029`。
它仍看不出 `S029` 是否在逻辑上真正串进了该 M 码的允许条件，所以只能当
第一道筛子，不能代替读梯形图。

## 8. 反模式

- 只写 `CMPE #50 R1 -> OUT A150`，不串 `S029`；
- 等待型 M 码从不拉低 `C38`，CNC 永远停在当前单节；
- 等待型 M 码把 `C38` 拉低后忘记恢复，或急停后仍保持 OFF；
- 按模板重写原机的 `C38` 支路，或把某台机的 `A050/A051/A052/A101`
  当成所有新代 PLC 的固定结构；
- 用固定延时代替到位信号；
- 没有超时报警；
- 同一输出有多个线圈，手动和自动各写一个；
- 把 `R1` 和 `R3` 写反（`R1`=M，`R3`=T）；
- 按 M 号猜夹紧/松开方向，不看 IO 点表。
