# R 寄存器规划地图

> 一句话结论：**先判断“这是什么性质的数据”，再选区；不要从“哪个号看着空”开始。**
>
> 机器可读版本：`syntec_lad/data/register-zones.json`。
> 查单个地址：`python scripts/run_syntec_lad.py lookup R2050`。
> 查宏 `@` 值：`python scripts/run_syntec_lad.py lookup @108001`。

---

## 1. 30 秒选区区

| 你要存什么 | 首选 | 不要用 | 关键限制 |
|---|---|---|---|
| 中间标志、流程步、互锁条件 | `A0~A511` | `C`、`S`、`Rxx.y` | `A` 才是中间继电器 |
| 操作员可改的参数（时长、间隔、次数） | `R81~R100` | 程序里的常数 | 对应 Pr3401~3420，阶梯只读 |
| 需要跨断电记住的数值 | `R193~R255`、`R6000~R7999`、`R10000~R10999` | `R50~R80`、`R256~R511` | 先确认没被刀号/应用占用 |
| 临时数值、过程数据 | `R50~R80`、`R256~R511`、`R1033~R2049`、`R3101~R4095` | 系统接口区 | 掉电不保持 |
| 铣床刀号数据 | `R103~R192`（已由系统定义） | 拿它存产量 | 不要占用刀号段 |
| 多 M 码同时执行 | `R2050~R2090`（先查 Pr3810） | 默认当空白区 | Pr3810=1 时被功能占用 |
| 刀具管理 | `R2100~R3100`（先查 Pr3228） | 默认当空白区 | Pr3228=1 时被功能占用，且保持 |
| M 码映射、插件交换、大块工艺数据 | `R20000~R65535` | 零散塞进系统区 | 宏只读，阶梯可读写 |
| 报警 | `R40~R49` | 自己另找 R 区 | 前 16 位警报，之后警告 |

## 2. R 分区总表

列含义：

- **阶梯**：梯形图程序能不能读/写。写代码只看这一列。
- **宏/HMI**：宏程序、人机界面能不能读/写。
- **位**：能不能写 `Rxxx.y`。
- **保持**：断电后值是否保留。
- **逐条**：该区权限按地址逐条定义，不能整片判只读/可写。

| 区段 | 归属 | 阶梯 | 宏/HMI | 位 | 保持 | 用途 / 条件 |
|---|---|---|---|---|---|---|
| `R0~R39` | CNC 系统接口 | 逐条 | 只读 | 是 | 否 | 模式、坐标、主轴、轴群等；写前查接口说明 |
| `R40~R49` | PLC 警报 | 读写 | 只读 | 是 | 否 | 报警/警告讯息 |
| `R50~R80` | 用户 | 读写 | 读写 | 是 | 否 | 临时值；标准包常用 R55~R56、R61~R68、R76~R78 |
| `R81~R100` | 用户参数 | **只读** | 只读 | 是 | 是 | Pr3401~3420 单向写入 |
| `R101~R102` | 刀具状态 | 读写 | 读写 | 是 | 是 | 储存在 IO 卡 |
| `R103~R255` | 用户 | 读写 | 读写 | 是 | 是 | R103~R192 铣床刀号 T1~T90；R193~R255 适合长期数值 |
| `R256~R511` | 用户 | 读写 | 读写 | 是 | 否 | 临时值和位；可位存取 |
| `R512~R639` | CNC 系统接口 | 逐条 | 只读 | 是 | 否 | 轴群、提示讯息、网络/警报 |
| `R640~R1023` | CNC 系统接口 | 逐条 | 只读 | **否** | 否 | 手轮倍率、合成进给、工作数、累计时间 |
| `R1024~R1032` | 条件占用 | 读写 | 读写 | 否 | 否 | 铣床自动分中/对刀；车床用户区 |
| `R1033~R2049` | 用户 | 读写 | 读写 | 否 | 否 | 临时值、HMI 交换 |
| `R2050~R2090` | 条件占用 | 读写 | 依条件 | 否 | 否 | Pr3810=0 用户区；=1 多 M 码功能占用 |
| `R2091~R2099` | 用户 | 读写 | 读写 | 否 | 否 | 临时值 |
| `R2100~R3100` | 条件占用 | 读写 | 读写 | 否 | 依条件 | Pr3228=0 用户区；=1 刀具管理占用并保持 |
| `R3101~R4095` | 用户 | 读写 | 读写 | 否 | 否 | 临时值、工艺数据 |
| `R4096~R5999` | CNC 系统接口 | 逐条 | 只读 | 否 | 否 | 刀具、CSV/串口 G 码等 |
| `R6000~R7999` | 用户（IO 卡） | 读写 | 读写 | 否 | 是 | 长期数值、板材/工艺数据 |
| `R8000~R8255` | CNC 系统接口 | **只读** | 读写 | 否 | 是 | Pr5001~Pr5500 映射；阶梯不要写 |
| `R8256~R9999` | CNC 系统接口 | **只读** | 只读 | 否 | 否 | 系统保留；R9000~R9999 部分版本给机器人 |
| `R10000~R10999` | 系统加值应用 | 读写 | 读写 | 否 | 是 | 中控、生产资讯、刀补模组等；先确认未占用 |
| `R11000~R14999` | CNC 系统接口 | **只读** | 只读 | 否 | 否 | 系统接口 |
| `R15000~R19999` | 系统加值应用 | 读写 | 读写 | 否 | 否 | 加值应用临时数据 |
| `R20000~R65535` | 用户 | 读写 | **只读** | 否 | 否 | M 码映射、插件、工艺应用 |

### 2.1 逐条定义区里已知的“阶梯可写”例外

`R512~R1023`、`R4096~R5999` 不能整片判只读。下面这些是手册明确可写的常见项，
完整清单仍以接口说明和 `references/panming/R512-R1023-权限表.md` 为准：

| 地址 | 用途 |
|---|---|
| `R520`、`R522~R525` | 轴群命令 |
| `R590~R599` | PLC 提示讯息 |
| `R603` | 禁止轴移动 |
| `R641~R656` | 手轮倍率 |
| `R831~R840` | MLC 参数 |

`R512~R517`（网络与警报）、`R521`（轴群状态）、`R526`（单节剩余距离）、
`R700`（合成进给实际值）、`R1004`（总工件数）等是典型只读项。

### 2.2 位存取的硬边界

- `R0~R639` 可以位存取。
- `R640` 及以上**不能**位存取；`R700.0`、`R1200.0` 编辑器不认。
- 中间标志优先用 `A`，不要用 `R50.0` 这种“在数据寄存器上抠一位”的写法。

## 3. `R@R`、`@` 公用变量、`#` 宏变量不是一回事

这是规划时最容易混淆的三套命名空间。

### 3.1 `R@R61`：阶梯图的间接寻址

官方写法是在寄存器编号前加 `R@`。`R@R61` 表示“先读 R61 的值，再把这个值
当作要访问的寄存器号”。

```text
R61 = 50
R50 = 10
读取 R@R61            // 先读 R61 得到 50，再读 R50，实际取出 10
```

要点：

- 官方语法是 `R@R61`，不是 `@R61`；本工具为兼容旧计划也接受 `@R61`，
  但交付文档里应写官方形式。
- `R@R61` 不是宏变量，也不是“R61 的别名”。
- 目标地址由运行时的 R61 值决定；R61 变了，下一条指令访问的寄存器就变了。
- 间接寻址的目标必须是控制器允许的寄存器号；越界或指向只读区，后果由程序承担。
- 间接寻址只支持整数寄存器号，不支持 `R@R61.5` 这种小数点语法。
- `AX RUN` 的 `PROG_IDX` 操作数没有官方间接寻址说明，工具生成时会拒绝。

### 3.2 `@` 公用变量：只有部分区段映射 R

`@` 是宏程序和人机界面的**公用变量**命名空间，不等于 R 寄存器。
只有下面三段是 R 的别名，其余是独立的 Double 变量：

| `@` 区段 | 说明 | 是否映射 R | 映射公式 / 例子 |
|---|---|---|---|
| `@0` | 空白 VACANT | 否 | — |
| `@1~@400` | 一般运算用公用变量，Double，R/W | **否** | `@100` 不是 `R100` |
| `@401~@655` | 对应 `R1~R255`，Long，R/W | 是 | `R = @ - 400`；`@401` → `R1`，`@655` → `R255` |
| `@656~@999` | 有记忆性公用变量，Double，R/W | **否** | — |
| `@1000` | 系统变数；旧版请勿使用 | 否 | 版本差异见下 |
| `@1001~@1999` | 有记忆性公用变量，Double，R/W | **否** | — |
| `@10000~@14095` | 对应 `R0~R4095`，Long，R/W | 是 | `R = @ - 10000`；`@10000` → `R0`，`@14095` → `R4095` |
| `@60000~@79999` | 扩充公用变量，Double，R/W | **否** | 需 No3813，且仅 CE 系统 |
| `@100000~@165535` | 对应 `R0~R65535`，Long，R/W | 是 | `R = @ - 100000`；`@108001` → `R8001`，`@120000` → `R20000` |

常见误判：

- `@100` 是普通公用变量，**不是 R100**。要访问 R100，宏里写 `@100100`
  （`100000 + 100`），或在阶梯图里直接写 `R100`。
- `@1~@400` 不是 `R1~R400`。它们不落在任何 R 区，不能用 R 分区表判断权限。
- `@108001` 不是 `R108001`（R 只到 65535），它是 `R8001` 的宏侧别名。

约束：

- `@1~@400` 关机后若要保持，需要 Pr3811 设定。
- `@656~@999`、`@1001~@1999`、`@60000~@79999` 本身有记忆性；
  `@60000~@79999` 还需 No3813，且仅 CE 系统支持。
- `@1000` 在 10.114.x/10.116.x 是系统变数，请勿使用；在
  10.118.56Z、10.118.60T、10.118.66M、10.118.70G、10.118.77 以后
  已改为有记忆性变量。
- DOS 版本只支持 `R0~R7999`，对应的 `@` 值也要按这个上限检查。
- `@` 映射到 R 后，**可写的 R 区**只有：
  `R50~R80`、`R101~R511`、`R1024~R4095`、`R5800~R7999`、
  `R10000~R10999`、`R15000~R65535`。
- 部分版本已限制通过 `@` 变量修改 `R8001~R8500`；会报
  `COR 16 不合法的变量存取`。要改这些参数，走 `Pr5001~Pr5500`。
- `@` 能写不等于“现场应该写”。系统接口区即使宏能写，也要先确认语义。

### 3.3 `#5001`：宏变量，不是 R

`#` 是宏程序的局部/公共变量命名空间，不是 R 寄存器。两者只在特定参数上建立映射：

| 参数 | R | 宏变量 | 说明 |
|---|---|---|---|
| `Pr3401~Pr3420` | `R81~R100` | — | 参数画面 → R → 阶梯 |
| `Pr5001~Pr5500` | `R8001~R8500` | `#5001~#5500` | 参数 ↔ R ↔ 宏变量 |
| `Pr5301` 等扩充参数 | `R8301` 等 | — | 参数号与 R 号按偏移对应 |

所以看到 `#5001` 不要直接当成 `R5001`；看到 `@108001` 也不要当成 `R108001`。

## 4. 规划流程（新建和修改都一样）

1. 先写“地址、符号、用途、权限、保持属性、所有者”表。
2. 用 `lookup` 查每个 R 的分区、权限、保持、位存取。
3. 条件区必须写明 Pr 条件：
   - `R2050~R2090` → `Pr3810=0/1`
   - `R2100~R3100` → `Pr3228=0/1`
   - `R1024~R1032` → 铣床自动分中/对刀是否启用，或车床用户区
4. 人确认后写进 `plan.resources`，`source=user` 或 `io-table`。
5. `plan-lint` 通过后再 build/patch。

### 4.1 例子：润滑泵

| 需求 | 选择 | 理由 |
|---|---|---|
| 打油进行中标志 | `A200` | 中间标志，不用 R |
| 打油时长 | `R81` | 操作员可在 Pr3401 改 |
| 打油间隔 | `R82` | 操作员可在 Pr3402 改 |
| 今日打油次数 | `R193` | 需要跨断电记住 |
| 本次循环计时 | `TM0` | 定时器 |

### 4.2 例子：M 码映射

| 需求 | 选择 | 理由 |
|---|---|---|
| M 码请求位 | `R25000` | 标准包常用 M 码自定义区 |
| 动作完成旗标 | `A210` | 中间标志 |
| 参数 | `R81~R100` | 操作员可改 |

### 4.3 反模式

- 把 `R50~R80` 当参数区：断电后参数回零。
- 把 `R103~R192` 当产量计数器：和铣床刀号数据打架。
- 写 `R81~R100`：阶梯写无效，改参数去参数画面。
- 写 `R8000~R8255`：宏可读写，但阶梯只读。
- 写 `R700.0`：该区不支持位存取。
- 看到 `R2050` 空着就用：先查 Pr3810。
- 看到 `R2100` 空着就用：先查 Pr3228。

## 5. 工具会怎么提醒

| 规则 | 级别 | 触发 |
|---|---|---|
| `resource_readonly_write` | error | 写 `R81~R100`、`R8000~R8255`、`R8256~R9999`、`R11000~R14999`、`I`、`S` |
| `r_bit_access_invalid` | error | 写 `R640+` 的位，如 `R700.0` |
| `r_retain_mismatch` | error / warning | `plan.resources` 的 `retain` 与分区不一致 |
| `r_system_write` | warning | 写逐条定义的系统接口区，且不在已知可写例外内 |
| `r_conditional_zone` | warning | 用条件占用区但没在 `note` 写明 Pr 条件 |
| `resource_missing` | warning | 用 I/O/C/S、`R0~R255` 或条件区但没登记 |

这些规则只能查“地址性质”，查不出“这个点现场到底接了什么”。
语法通过 ≠ 点位正确。

## 6. 证据来源与边界

- R 分区主表：新代《CNC and PLC Interface》R 寄存器分配表。
- 逐条权限：R512~R1023 权限表与接口说明。
- `@` 映射：新代 Confluence《Macro变数规格》公用变量表；只取区段规则，不收录站点/页面 ID。
- 现场常用区段：Confluence 标准包 IO&R 使用区间；只取通用模式，不收录客户名。
- 本页是规划辅助，不替代目标机台的接口说明、IO 点表和原生 LadDLL 校验。

未联网查 Confluence 时，交付说明必须写“未联网云端验证”，不能把本页当成最新规格。
