# PLC 换刀改造：案例评审与状态机检查

> 一句话结论：换刀 PLC 的安全不取决于某个模板，而取决于状态机、完成信号、
> 互锁、单步、急停收尾和软限位是否与本机机械、宏、IO 点表一致。
> 本文是评审方法，不是可直接上机的通用换刀程序。

本文来自一次立式钻攻机“宏换刀改为 PLC 轴换刀”的现场记录，并用官方
《阶梯图编写开发》《PLC 元件介绍》《PLC 介面说明》《软体行程极限应用手册》
交叉核对。凡是客户机台专用地址，本文只保留结构关系，不把它们写成通用规则。

---

## 1. 证据等级

| 等级 | 例子 | 用法 |
|---|---|---|
| 官方规则 | M/S/T 完成用 `C38`；第三软限位用 `C83/R638`；复位可中断 PLC 轴动作 | 所有机台适用 |
| 官方示例 | MSD 两状态 `A50/A51`；非等待 M 码 `A70` | 学状态语义，地址按本机点表替换 |
| 现场骨架 | 某台机已验证的 `A050/A051/A070` C38 支路 | 原机保留或整段复制，不能当所有机型的标准 |
| 单机结构 | 某客户的换刀步号、故障步、`R58.0` 关第三软限位 | 只能当案例，换机必须重新核对 |

判断顺序：

1. 官方接口/参数页能证明的，才写成硬规则；
2. 真实 `.lad` 能证明的，标成“现场观察”；
3. 两者冲突时并列，不能自行择一；
4. 只有一次现场记录、没有第二证据的，降级为“案例/待确认”。

## 2. 写之前先做的事

1. `inspect` 原 `.lad`，记录 SHA256、记录数、程序边界和原 `C38` 支路。
2. `resources` 盘点 I/O、A、C、S、R、TM、CT，并做**位级**占用扫描。
3. 画一张资源表：地址、符号、用途、读/写权限、保持属性、所有者、来源。
4. 确认宏与 PLC 的握手：命令、状态、故障步、完成、复位分别由谁写。
5. 确认本机 `Pr17`、点位寄存器单位、轴群、软限位参数和 IO 点表。
6. 以上由人确认后，才进入 plan/change。

不要从“哪个 R 号看起来空”开始选地址。也不要写“R1000 以下都不能用”这种
过度概括：正确做法是查分区和已知系统/条件占用区，再对目标块做位级扫描。
例如某台机的 `R256.01~R256.19`、`R257.01~R257.06` 被面板按键旗标占用，
整字写 `R256` 会破坏键值；这是该案例的占用事实，不是“R256 永远不能用”。

## 3. 状态机

### 3.1 每一步都要有进入条件、动作、退出条件

步表至少写清：

| 字段 | 必须回答的问题 |
|---|---|
| 步号 | 正常步、等待步、故障步分别是哪些 |
| 进入条件 | 上一个动作真的完成了吗，还是只看命令已发出 |
| 动作 | 输出、数据寄存器、轴命令、计时器分别做什么 |
| 退出条件 | 实际到位信号、刀号一致、允许放行分别是什么 |
| 超时 | 超时后进步号几，是否停轴、报警、清命令 |
| 急停 | 该步急停时停在什么位置，哪些输出要撤销 |

完成条件必须用实际反馈，不能用“命令已发出”或固定延时代替。模拟器能跑通
只证明逻辑链路，不证明机械互锁。

### 3.2 模式、暂停、复位

- 模式位是**起动前条件**，不是步骤推进条件。把自动模式位串进每一步，
  换刀中切模式就会让流程停在半路。
- 暂停信号不是步骤许可。用暂停信号驱动“下一步”，暂停时流程根本不能走。
- 复位语义必须先定义：
  - 流程中允许复位：必须定义停轴、清状态、机构中途退出办法；
  - 流程中禁止复位：在原有复位/暂停支路串流程旗标，不能只靠停轴兜底。
- 官方说明复位可中断执行中的 PLC 轴动作。若规格是“换刀中复位无效”，
  停轴条件不要包含复位位；否则复位会把轴停在刀库中间。

### 3.3 单步

- 每个独立机械动作占独立步号，不能把“转盘”和“下行”挤在同一个许可位里。
- 一次按键只放行一个动作；动作完成后清除许可，等下一次按键。
- 转盘、松夹刀、门、轴定位等有机械风险的动作，各自有到位确认和超时。
- 单步计数要按实际步表核对，不能只按“动作段数”估。

### 3.4 计时器

- `TIM` 必须显式写单位。`#00150` 在 0.1 s 精度下是 15 s，在 1 ms
  精度下是 0.15 s；不要靠默认单位猜。
- 计时器只在“动作已经启动、还没到位”时计时。单步等人按键期间不能继续
  计时，否则会误报超时。
- 到位后要复归计时条件，避免下一步刚进入就带着旧计时。

### 3.5 点位和参数

- 点位从 HMI/参数寄存器读，不在梯图里写死。每台机的换刀点、安全点、
  减速点都不同。
- 点位寄存器可能存 mm，也可能存 BLU。写入运动指令前必须确认单位，
  不能只看数值大小。
- 速度、加减速、窗口、超时都是机台参数，不是模板常数。

### 3.6 急停与故障收尾

急停不是“只清步号”。至少检查：

1. 停轴/停输出；
2. 清步号、命令、完成旗标、故障码；
3. 恢复流程中关闭的安全功能（例如第三软限位、门锁、允许信号）；
4. 松开急停后不得自动续走，必须重新起动；
5. 故障步退出时也要落在安全状态，不能在危险位置恢复保护后立刻报警。

## 4. 互锁

### 4.1 刀库与轴

- 轴必须先到安全点，刀盘才有让刀空间；安全点要用实际机械坐标确认，
  不能只看“步号已到”。
- 刀盘旋转前要有“轴已停稳、刀盘已让开、目标刀号有效”的互锁。
- 刀盘到位条件至少包含“刀盘静止/就绪”和“当前刀号=目标刀号”，
  少一个都可能在下行时撞刀。
- 换刀中手动转刀盘必须被流程旗标挡住；否则手动与自动会同时驱动刀盘。

### 4.2 第三软限位

官方《软体行程极限应用手册》明确：

- 第三软体行程极限由 `C83` 或 `R638` 开关；
- `R638.0=0` 时开关来源是 `C83`，`R638.0=1` 时来源是 `R638` 的轴群位；
- `C83=ON` 表示保护，`OFF` 表示不保护；
- 范围由 `Pr2441~Pr2480` 决定，动态范围可由宏改写 `#1941~#1958` /
  `#1961~#1978`。

第一软限位是 `Pr2401~Pr2440` 的固定行程保护，没有 `C83` 这样的开关位。
不要因为“第一软限位没有 C bit”就断定换刀软限位做不了。

如果流程会关闭第三软限位，急停/故障收尾必须把它恢复到保护状态。某案例用
宏写 `@458`，对应 `R58.0`，再由原机 `C83` 支路的 `!R58.0` 条件关闭保护；
这是该机台的映射，不是通用地址。换机时要找本机实际的第三软限位开关来源。

## 5. 单机案例地址只做结构参考

下面只写角色，不写具体地址：

| 角色 | 方向 | 说明 |
|---|---|---|
| 换刀命令寄存器 | 宏 → PLC | 空闲、整套换刀、同刀回零等命令 |
| 目标刀号 | 宏 → PLC | 与刀库程序共享时必须定义谁写 |
| 状态寄存器 | PLC → 宏 | 动作中、回零完成、整套完成、故障 |
| 故障步号 | PLC → 宏 | 宏报警时能定位到具体步 |
| 流程旗标 | PLC → 复位/暂停/手动支路 | 挡住换刀中的复位、暂停、手动刀盘 |
| 刀盘转位请求 | PLC → 刀库程序 | 电平保持还是脉冲必须写清 |
| 软限位关闭 | 宏 → PLC | 必须与本机原支路一致，不能猜地址 |

某案例的 `@470 → R70`、`@458 → R58.0` 只说明该地址落在 `@401~@655`
这段映射里（`R=@−400`）。`@1~@400`、`@656~@999` 等并不映射 R；
跨宏/梯图沟通时统一写一种，并在批注里标出另一种。


## 6. PLC 轴换刀补充

正式版不提供 PLC 轴生成和轴安全校验，本节不包含轴动作示例。不得用其他
版本生成轴逻辑后回填正式版；涉及轴换刀时停止写入，改用 Alpha 版并完成
专项安全评审。

## 7. 交付前检查表

| 项目 | 必须确认 |
|---|---|
| 原文件 | SHA256、记录数、编码、程序边界已记录 |
| C38 | 原机支路保持原样；新 M/T 码只改动作和完成条件 |
| 资源 | 所有 I/O、A、C、S、R、TM、CT 登记来源；做过位级占用扫描 |
| 模式 | 步骤推进不以模式/暂停为许可；起动前才检查模式 |
| 单步 | 每个动作独立步号；一次按键只走一段 |
| 计时 | 单位显式；到位复归；等待按键期间不计时 |
| 点位 | 从 HMI/参数读；单位确认；没有硬编码常数 |
| 互锁 | 安全点、刀盘就绪、刀号一致、轴停稳 |
| 急停 | 停轴、清状态、恢复输出/软限位、不得自动续走 |
| 复位 | 允许/禁止已定义；停轴条件与规格一致 |
| 故障 | 每一步都有超时、故障步、报警和退出路径 |
| 验证 | 先低速/空载；模拟器能过不等于真机安全 |

## 8. 反模式

- 把某台机的 C38 支路（包括 `A050/A051/A052/A101/A188` 这类组合）
  当成所有新代 PLC 的通用模板；
- 用模式位或暂停信号做步骤推进；
- 单步许可跨多个机械动作复用；
- 计时器在等待操作员时继续计时；
- 用固定延时代替到位信号；
- 点位写死，换机就错；
- 急停只清步号，不恢复被流程关闭的输出和软限位；
- 故障分支恢复软限位时，轴还在危险位置；
- 先把轴停在刀库中间，再要求按复位继续；
- 用模拟器“能跑完”证明真机互锁安全。
